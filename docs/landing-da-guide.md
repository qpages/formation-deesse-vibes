# Guide de Direction Artistique pour Landing Pages

> Objectif : transformer une intention vague comme `premium futuristic website` en une direction artistique claire, exploitable et cohérente.

---

# 1. La formule à retenir

Utilise cette structure :

```txt
[QUALITY]
+ [STYLE]
+ [ERA / CULTURE]
+ [MOOD]
+ [TYPOGRAPHY]
+ [LAYOUT]
+ [MATERIAL]
+ [IMAGERY]
+ [COLOR]
+ [INTERACTION]
+ [PRODUCT / INDUSTRY]
+ [PAGE TYPE]
```

Exemple :

```txt
/impeccable retro-futurist AI conference website,
1970s space-age optimism,
sophisticated and experimental,
oversized neo-grotesk typography,
strict Swiss editorial grid,
subtle film grain and metallic surfaces,
archival aerospace photography mixed with abstract CGI,
warm off-white with electric orange accents,
cinematic interactions,
highly usable
```

---

# 2. Les axes les plus importants

Si tu veux aller vite, définis au minimum :

```txt
STYLE
MOOD
TYPOGRAPHY
LAYOUT
COLOR
IMAGERY
```

Ces 6 axes suffisent souvent pour obtenir une DA forte.

# 19. Ce qu'il faut éviter

## Trop vague

```txt
modern
beautiful
cool
clean
professional
futuristic
premium
```

Ces mots seuls ne donnent presque aucune direction.

---

## Trop de styles simultanément

Mauvais :

```txt
Swiss brutalist Y2K Art Deco minimal cyberpunk website
```

Préférer :

```txt
Swiss editorial structure
+ Y2K material language
```

Une direction principale + une influence secondaire.

---

## Copier une marque sans comprendre pourquoi

Évite :

```txt
make it like Apple
make it like Linear
make it like Stripe
```

Décompose la référence :

```txt
restrained product photography,
large whitespace,
precise typography,
minimal UI,
subtle interaction
```

# 20. Principe clé

Ne pense pas seulement :

```txt
À quoi le site doit ressembler ?
```

Pense :

```txt
Quelle culture visuelle ?
Quel système graphique ?
Quel comportement d'interface ?
```

Formule idéale :

```txt
CULTURAL REFERENCE
+
GRAPHIC SYSTEM
+
INTERACTION SYSTEM
```

Exemple :

```txt
1970s aerospace futurism
+
Swiss information design
+
cinematic interaction
```

C'est souvent beaucoup plus fort que :

```txt
cool futuristic website
```

---

# 21. Checklist avant de développer

* [ ] Le style principal est identifiable en 2 secondes
* [ ] Il n'y a pas plus de 1 à 2 influences majeures
* [ ] La typographie a une direction claire
* [ ] La grille est définie
* [ ] La densité visuelle est volontaire
* [ ] La palette a une logique
* [ ] Les images suivent une direction unique
* [ ] Les textures servent la DA
* [ ] Le motion design correspond au mood
* [ ] Les composants UI restent cohérents
* [ ] La DA ne dégrade pas la lisibilité
* [ ] Le responsive conserve la personnalité du desktop
* [ ] Les CTA restent immédiatement identifiables
* [ ] L'expérience reste accessible
* [ ] Le résultat ressemble à un système, pas à une collection d'effets

# 22. Raccourci mental

Quand tu construis un nouveau site, réponds simplement à :

```txt
1. STYLE
2. MOOD
3. TYPE
4. GRID
5. MATERIAL
6. IMAGE
7. COLOR
8. MOTION
```

Puis transforme les réponses en prompt.

Exemple :

```txt
STYLE    → retro-futurist
MOOD     → optimistic + sophisticated
TYPE     → oversized grotesk
GRID     → strict Swiss grid
MATERIAL → grain + metallic
IMAGE    → archival aerospace photography
COLOR    → off-white + orange
MOTION   → subtle cinematic
```

Résultat :

```txt
/impeccable retro-futurist website,
optimistic and sophisticated,
oversized grotesk typography,
strict Swiss grid,
subtle grain and metallic surfaces,
archival aerospace photography,
warm off-white with electric orange accents,
subtle cinematic interactions
```
